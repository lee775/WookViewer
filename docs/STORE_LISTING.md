# 원스토어 / Play Store 등록용 텍스트 초안

> 원스토어 한국어 우선. 분량 한도는 원스토어 기준으로 작성 (Play Store 도 동일하게 들어감).
> 각 항목 등록 시 그대로 복붙해도 되고, 필요 부분만 수정해도 됨.

---

## 앱 이름
```
욱뷰어 - 문서 뷰어 / 편집기
```

## 앞 설명 (짧은 설명) — 한도 ~80자
```
PDF · DOCX · PPTX · XLSX · HWP · 텍스트 · 이미지까지 한 앱에서 보고 편집하세요. 광고 없음.
```

- 1차: **생산성**
- 2차: 도구

```
오피스 편집, 마크다운, 텍스트 편집기, 무광고, 무료
```

## 자세한 설명 — 한도 4000자

```
욱뷰어는 한국 사용자를 위한 통합 문서 뷰어 및 편집기입니다.
한 앱에서 PDF, 워드, 엑셀, 파워포인트, 한글(HWP/HWPX), 텍스트, 이미지를 보고 편집할 수 있습니다.

■ 지원하는 파일 형식

문서:
• PDF
• DOCX (Microsoft Word)
• PPTX (Microsoft PowerPoint)
• XLSX (Microsoft Excel)
• HWP (한글 워드프로세서)
• HWPX (한글 XML)
• ODT / ODS / ODP (오픈도큐먼트)

텍스트:
• TXT, LOG
• MD (Markdown)
• CSV / TSV
• JSON, XML, YAML, INI, TOML, CONF

이미지:
• JPG, PNG, GIF, WebP, BMP, HEIC, HEIF


■ 주요 기능

📄 뷰어
• LibreOffice 엔진 기반 — 원본 레이아웃과 서식을 그대로 표현
• 페이지 단위 렌더링 — 긴 문서도 끝까지 끊김 없이 표시
• 페이지 썸네일 그리드
• 부드러운 핀치 줌 / 더블탭 줌
• PDF 텍스트 모드 (선택·복사·검색 가능)
• 페이지 내 키워드 검색 + 매치 하이라이트

✏️ Office 문서 편집 (DOCX / PPTX / XLSX)
• 한글 입력 (자모 조합 지원)
• 글꼴 변경 (문서에 포함된 글꼴 목록에서 선택, 미리보기 제공)
• 글꼴 크기 (8 pt ~ 72 pt)
• 글자색 / 형광펜 (색상 미리보기)
• 굵게 / 기울임 / 밑줄
• 정렬 (왼쪽 / 가운데 / 오른쪽 / 양쪽)
• 글머리 기호 / 번호 매기기
• 길게 눌러 단어 선택 (선택 영역 시각화)
• 복사 / 붙여넣기 (Android 클립보드 연동)
• 실행 취소 / 다시 실행
• 화면 탭으로 커서 위치 이동 (LOK 커서 깜빡임 표시)

📝 텍스트 / Markdown 편집
• TXT, MD 파일 직접 편집 + 저장
• 다른 이름으로 저장 (SAF 사용)
• 한국어 인코딩 자동 감지 (EUC-KR, CP949 포함)

🔄 다른 포맷으로 저장
• DOCX → PDF / ODT / DOCX(사본)
• PPTX → PDF / ODP / PPTX(사본)
• XLSX → PDF / ODS / XLSX(사본)

🔐 비밀번호 보호 문서
• PDF 비밀번호 해제 후 보기
• Office 파일 (DOCX / PPTX / XLSX) Agile · Standard 암호화 해제
• HWPX 비밀번호 해제

📑 편의 기능
• 북마크 (페이지 단위 + 메모)
• 최근 문서 목록
• PDF 목차 (Outline) 자동 표시
• XLSX 시트 탭 / PPTX 슬라이드 페이지
• 원본 파일 / 페이지 텍스트 공유 (Share Intent)


■ 개인정보 / 광고

• 외부 서버에 어떠한 데이터도 전송하지 않습니다.
• 인터넷 권한을 요청하지 않습니다.
```

## 스크린샷 권장 구성 (직접 촬영 필요)

순서대로 4-6 장 추천:
1. 메인 파일 목록 화면
2. PDF 또는 DOCX 보기 화면 (실제 한국어 문서)
3. PPTX 슬라이드 보기 (이미지·표 포함된 슬라이드)
4. Office 편집 모드 (도구바 + 커서)
5. 색상 / 글꼴 팔레트 펼친 모습
6. 검색 결과 하이라이트
