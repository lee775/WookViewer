# 실기기 종합 검증 가이드 (v0.4.1)

> 이 문서는 빌드된 APK를 실제 안드로이드 기기에 설치해 4종 포맷 모두를 검증하는 절차를 안내합니다.
> 발견된 이슈를 기록하고 해결할 수 있도록 단계별 체크리스트를 제공합니다.

## 1. APK 설치

### 1.1 APK 위치
```
C:\WOOK\WookViewer\apk-output\WookViewer-debug\WookViewer-debug.apk   (~18 MB)
```

### 1.2 폰으로 전송 — 3가지 방법 중 하나 선택

| 방법 | 절차 | 비고 |
|---|---|---|
| **USB 케이블** (가장 빠름) | PC와 폰 USB 연결 → "파일 전송" 모드 → APK 파일을 폰의 `Download` 폴더로 드래그 | 평소 사진 옮길 때와 동일 |
| **Google Drive** | PC에서 APK를 Drive 업로드 → 폰 Drive 앱에서 다운로드 | 인터넷 필요 |
| **이메일 첨부** | 본인 이메일로 첨부 발송 → 폰에서 첨부 다운로드 | Gmail은 파일 크기 25MB 이하 OK |

### 1.3 폰에서 설치
1. 폰의 **파일 매니저** 앱(예: Files by Google, 갤럭시 내 파일)에서 `Download` 폴더 열기
2. `WookViewer-debug.apk` 탭
3. 첫 설치 시 **"출처를 알 수 없는 앱 설치 허용"** 권한 요청 → 허용
4. 설치 완료 후 "WookViewer" 앱 아이콘 등장

> **알림**: Android 8.0 이상에서는 출처를 알 수 없는 앱 권한이 *앱별로* 부여됩니다. 위 단계에서 파일 매니저 앱에 한 번 허용하면 됩니다.

### 1.4 설치 확인
앱 실행 → 상단 좌측에 **"최근 문서"** 와 그 아래 **"v0.4.1 · debug"** 부제목이 보이면 정상.

## 4. 알려진 한계 (이슈 아님)

다음은 v0.4 설계상 의도된 한계로, *이슈로 보고할 필요 없습니다*:

- HWP/DOCX/PPTX 모두 **표/이미지/도형/서식**은 단순화 또는 무시 (배너로 안내됨)
- HWP의 **페이지 번호**는 원본과 다름 (논리 분할)
- PPTX의 **슬라이드 순서**는 파일명 기준 — 사용자가 PowerPoint에서 슬라이드를 재배치한 경우 표시 순서와 다를 수 있음 (v0.5 범위)
- **암호화 PDF** 미지원 (PdfRenderer 한계)
- **머리말/꼬리말, 댓글, 발표자 노트** 무시
- **한글 2002 이전(.hwp 3.0)** 미지원
